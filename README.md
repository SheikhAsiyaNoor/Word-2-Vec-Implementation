# Introduction
The objective of this assignment was to implement the Skip-gram with Negative Sampling for word embeddings. The model needed to be trained on a provided Wikipedia dump. The resulting vectors were to be evaluated through Similarity Analysis, Word Analogy Task, and Bias Detection.

# How to run
## 1. Train the model
In your terminal of choice, run `python train_gensim.py`

## 2. Run the model
Run the command `python evaluate_gensim.py`
